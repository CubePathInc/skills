# CubePath skills

Official [Agent Skills](https://agentskills.io) for managing
[CubePath Cloud](https://cubepath.com) from AI coding agents (Claude Code, Codex,
Gemini CLI, Cursor and any other agent that reads `SKILL.md` skills).

They teach the agent to drive [cubecli](https://github.com/CubePathInc/cubecli)
safely: resolve IDs instead of guessing them, parse `--json` output, confirm
before anything destructive or billable, and wait for asynchronous operations.

| Skill | Covers |
|---|---|
| [cubepath-cli](plugins/cubepath/skills/cubepath-cli/SKILL.md) | Install, login and profiles, JSON output, IDs, confirmations, errors. Base for the others. |
| [cubepath-vps](plugins/cubepath/skills/cubepath-vps/SKILL.md) | VPS lifecycle, cloud-init, backups, availability groups, baremetal |
| [cubepath-networking](plugins/cubepath/skills/cubepath-networking/SKILL.md) | Private networks and routes, NAT gateways, floating IPs, load balancers |
| [cubepath-dns-cdn](plugins/cubepath/skills/cubepath-dns-cdn/SKILL.md) | DNS zones and records, CDN zones, origins, rules, WAF, metrics |
| [cubepath-kubernetes](plugins/cubepath/skills/cubepath-kubernetes/SKILL.md) | Managed Kubernetes clusters, node pools, addons, exposing services |
| [cubepath-object-storage](plugins/cubepath/skills/cubepath-object-storage/SKILL.md) | S3-compatible buckets, access keys for S3 clients, replication, CDN delivery, usage and cost |

## Install

You need [cubecli](https://github.com/CubePathInc/cubecli) 1.8.0 or later,
logged in with `cubecli login`.

### Claude Code

```
/plugin marketplace add CubePathInc/skills
/plugin install cubepath@cubepath
```

### With cubecli

```bash
cubecli skills install
```

Installs the latest release for the agents found on your machine: Claude Code
(`~/.claude/skills`) and Codex, Gemini CLI and Cursor (`~/.agents/skills`).
`cubecli login` offers to do it after your first login. `cubecli skills update`
keeps them current.

### Manually

Download `cubepath-skills-vX.Y.Z.tar.gz` from the
[releases](https://github.com/CubePathInc/skills/releases), check it against
`SHA256SUMS`, and copy the folders under `skills/` into your agent's skills
directory (`~/.claude/skills/` for Claude Code, `~/.agents/skills/` for Codex,
Gemini CLI and Cursor).

## How it stays accurate

Each skill ships a `reference/` folder with the exact cubecli commands and flags,
generated by `cubecli docs markdown`. `scripts/validate.py` checks that every
`cubecli` command and flag written in a `SKILL.md` exists in that reference, and
CI regenerates it weekly against the latest cubecli release and fails when it
drifts.

## Development

```bash
scripts/generate-reference.sh   # refresh reference/ from the cubecli in PATH
scripts/validate.py             # structure, links, commands and flags
scripts/build-release.sh        # dist/ tarball + SHA256SUMS
```

Release: bump `version` in `manifest.json` and
`plugins/cubepath/.claude-plugin/plugin.json` (they must match), commit, and push
a `vX.Y.Z` tag. The release workflow publishes the tarball.

Writing guidelines for skills:

- Only document commands and flags that exist; the validator enforces it.
- Prefer `--json` and show the jq path of the fields that matter.
- Every destructive or billable action needs an explicit user confirmation
  before `--force`.
- Never have the agent ask for, print or store credentials.
