# cubecli config

Configure CubeCLI

## `cubecli config setup`

Log in the 'default' profile (same as 'cubecli login default')

Usage: `cubecli config setup [flags]`

- `--no-browser`: Print the login URL instead of opening a browser
- `--token`: Store an API token instead of logging in with the browser

## `cubecli config show`

Show current configuration

Usage: `cubecli config show`
