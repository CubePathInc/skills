# cubecli command reference

Generated from the cubecli command tree with `cubecli docs markdown`. Do not edit by hand.

## Global flags

- `--json`: Output in JSON format
- `--profile string`: Profile to use (overrides CUBE_PROFILE and current profile)
- `-v, --verbose`: Enable verbose output

## Command groups

- `auth`: Log in, log out and inspect credentials
- `availability-group`: Manage VPS availability groups
- `baremetal`: Manage baremetal servers
- `cdn`: Manage CDN zones and distribution
- `config`: Configure CubeCLI
- `ddos-attack`: Manage DDoS attack information
- `dns`: Manage DNS zones and records
- `floating-ip`: Manage floating IPs
- `kubernetes`: Manage Kubernetes clusters
- `lb`: Manage load balancers
- `location`: Manage locations
- `login`: Log in to CubePath in the browser and store the session in a profile
- `logout`: Revoke the session of a profile and remove its credentials
- `nat-gateway`: Manage NAT gateways
- `network`: Manage networks
- `profile`: Manage authentication profiles
- `project`: Manage projects
- `skills`: Install the CubePath skills for AI coding agents
- `ssh-key`: Manage SSH keys
- `update`: Update CubeCLI to the latest version
- `version`: Show CubeCLI version
- `vps`: Manage VPS instances
